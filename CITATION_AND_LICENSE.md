# Citation and reuse

## How to cite the software

Mahalakshmi, S., & Bagavathi Lakshmi, R. (2026). *VIRCON-ERT: An Event-Aware Triage Transformer for Humanitarian Social Media Classification and Disaster Response — Reproducibility Materials* [Software]. Zenodo. https://doi.org/10.5281/zenodo.23752634

For an IJIES manuscript citing the v1.1.0 source snapshot, use the NEW version-specific DOI shown on the Zenodo v1.1.0 record once it is archived.

Source repository: https://github.com/Mahamangai/VIRCON-ERT-Reproducibility

Cite the associated manuscript and the original CrisisBench, HumAID, DistilBERT, and MiniLM works as appropriate.

## Licensing and source data

The Zenodo record currently displays Creative Commons Attribution 4.0 (CC BY 4.0). This record-level licence does not override any third-party dataset terms or grant rights to redistribute original social-media messages. A separate repository-level software licence has not been supplied in the archived package; do not assume that code reuse is unrestricted merely because the repository is public.
